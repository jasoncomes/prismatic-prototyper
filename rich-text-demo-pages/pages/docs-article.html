Writing your first flow

A flow is a trigger plus an ordered list of steps. This page builds one from an empty directory to a running instance, and should take about ten minutes.

Before you start

  • Node 20 or later
  • A Prismatic account on the Build & Deploy plan or above
  • The command line tool, installed with npm i -g @prismatic-io/prism

1. Scaffold the integration

prism integrations:init my-integration
cd my-integration
npm install

That writes a working integration with one flow and one step. Everything after this edits it.

2. Define the flow

Give the flow a name, a stable key and a trigger. The steps array starts empty.

const flow = {
  name: "weekly",
  stableKey: "weekly",
  description: "Runs every Monday at 09:00",
  steps: [],
};

Note. stableKey must not change once the integration is published. References point at it, and renaming it breaks every step that reads the output.

3. Add a step

Each step names a component, an action on it, and the inputs that action takes.

steps: [
  {
    name: "Render",
    action: { component: "richTextDemo", key: "publishPage" },
    inputs: {
      title: { type: "value", value: "Weekly" },
      body: { type: "template", value: "<h1>Hello Procter & Gamble</h1>" },
    },
  },
]

4. Publish and deploy

prism integrations:import --path ./integration.yml
prism integrations:publish

Then create an instance for Procter & Gamble and run a test.
