Writing a flow

A flow is a trigger plus a list of steps. This page builds one from scratch.

1. Scaffold the integration

prism integrations:init my-integration
cd my-integration
npm install

2. Define the flow

Give it a name and a trigger. The steps array starts empty.

const flow = {
  name: "weekly",
  stableKey: "weekly",
  description: "Runs every Monday",
  steps: [],
};

Note. stableKey must not change once published — references point at it.

3. Publish

Publish with prism integrations:publish, then create an instance for Procter & Gamble.

Troubleshooting

  • Invalid reference — the step named does not exist in this flow
  • invalid_payload — a value broke the JSON body; see escaping
